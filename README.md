What CRUD means, what mongoDB is and why they are important to your project?


CRUD is short for Create, Read, Update, and Delete. I used Postman to test my database CRUD logic. CRUD operations are important to my project since the 
login/register portion needs user interaction. MongoDB is a document database it uses a flexible schema to store data, it diverges from traditional databases such as SQL databases which stores data in tables of rows or columns. Each MongoDB document can have an unique structure, this is very valueable to my project because it allows me to store different types of movie data.
